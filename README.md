# Novex

**Novex** — ИИ-платформа персонального образования для школьников Казахстана (7–12 классы), которая даёт одинаково качественное обучение независимо от школы и региона.

Проект создан для **Future Minds Hackathon 2026 — Track 2: Social Impact Challenge**. Продакшн-сборка развёрнута на [novex-edu.vercel.app](https://novex-edu.vercel.app).

## Проблема

- Качество образования в Казахстане сильно различается между городскими и сельскими школами.
- У учеников в регионах нет доступа к сильным репетиторам и дополнительным материалам.
- Учителя перегружены и не могут закрыть пробелы каждого ученика.
- Материалы для подготовки к ЕНТ, олимпиадам и поступлению разрознены и не адаптированы под уровень.

## Продукт

Цикл обучения из 5 шагов: ученик регистрируется → выбирает класс, предметы и цель (ЕНТ, олимпиада, повторение, поступление) → платформа рекомендует материалы под его уровень → ученик решает задания и получает пошаговую обратную связь от ИИ → учитель отслеживает прогресс класса через панель.

### Возможности

- **Профориентационный тест** (`/career`) — определяет направления и предметы, которые стоит изучать; результат кешируется локально и синхронизируется с БД.
- **Диагностика уровня** (`/onboarding`) — адаптивный тест по выбранным предметам, идёт после профориентации.
- **Дашборд ученика** (`/dashboard`) — прогресс по темам, слабые места, достижения, XP и стрики.
- **Обучение** (`/learn`) — уроки по предметам, «планеты» направлений (академическая база, жизненные навыки, навыки будущего), плейсмент-тесты.
- **ИИ-тьютор «Академик»** — чат с пошаговыми объяснениями ошибок на языке ученика, выбор из нескольких моделей (Claude / GPT).
- **План подготовки** (`/plan`) — персональный роадмап к цели с дедлайнами.
- **Практика** (`/practice`) — задания с проверкой и объяснениями.
- **Панель учителя** (`/teacher`) — статистика по классу, прогресс каждого ученика, добавление тем и заданий.
- **Сообщество** (`/community`) — каналы, сообщения, реакции, жалобы, вложения.
- **Геймификация** — внутренняя валюта «Новасы» ⚙ (начисление триггерами БД, трата через RPC `spend_novas`), XP, достижения.
- **Web Push-уведомления** — напоминания о дедлайнах и повторении (service worker `public/sw.js` + edge-функция `dispatch-notification-push`).
- **Три языка интерфейса** — русский, казахский, английский (переключение на лету, выбор сохраняется).

### Три робота Novex

Визуальная тема продукта — три робота-наставника:

| Юнит | Имя | Направление |
|---|---|---|
| `NOV-01` | Академик | Академическая база: диагностика, карта знаний, адаптация сложности, объяснения, роадмап к ЕНТ |
| `NOV-02` | Практик | Жизненные навыки: финансы, коммуникация, психология, продуктивность |
| `NOV-03` | Кибер | Навыки будущего: программирование, предпринимательство, креативность, карьера |

## Технологический стек

- **Фронтенд:** React 18, TypeScript 5.8 (strict), Tailwind CSS v4 (`@tailwindcss/vite`, тема через `@theme` в `index.css`), Framer Motion, lucide-react
- **Роутинг:** react-router-dom 6
- **Сборка:** Vite 6 (dev-сервер на порту 3000)
- **Бэкенд:** Supabase — аутентификация (email + Google OAuth, PKCE), PostgreSQL с Row Level Security, Storage (аватары, вложения сообщества), Edge Functions
- **ИИ:** edge-функция `ai-chat` проксирует запросы к LLM-провайдерам — ключи живут только в серверных секретах, клиент к API напрямую не обращается
- **Хостинг:** Vercel

## Архитектура

### Структура проекта

Плоская структура, без `src/`:

```
index.html / index.tsx / index.css   → точка входа, глобальные стили и @theme
App.tsx                              → роутер-оболочка (BrowserRouter → Language/Auth providers → Header/Routes/Footer)
components/                          → страницы и общие компоненты (Header, Footer, ProtectedRoute…)
  components/landing/                → секции лендинга (по файлу на секцию)
  components/auth/                   → вход, регистрация, OAuth callback
  components/career/                 → профориентационный тест
  components/diagnostic/             → диагностика уровня (онбординг)
  components/dashboard/              → дашборд ученика
  components/learn/                  → уроки, «планеты» направлений
  components/plan/ · practice/       → план подготовки, практика
  components/teacher/                → панель учителя
  components/community/              → сообщество (каналы, сообщения)
  components/chat/                   → ИИ-тьютор
  components/robots/                 → общий SVG-арт роботов (RobotAvatar, GearDecor, CircuitTrace)
context/                             → AuthContext, LanguageContext
services/                            → слой доступа к данным: supabaseClient, aiService, novasService,
                                       communityService, notificationsService, practiceService
constants/                           → контент: уроки, диагностика, направления, школы
utils/i18n.ts                        → Lang ('ru'|'kk'|'en'), Localized, loc()
supabase/migrations/                 → миграции БД (profiles, RLS, триггеры)
supabase/functions/                  → edge-функции: ai-chat, dispatch-notification-push
public/sw.js                         → service worker для Web Push
```

### Основные маршруты

Публичные: `/` (лендинг), `/pricing`, `/faq`, `/login`, `/signup`. Защищённые (`ProtectedRoute`): `/profile`, `/onboarding`, `/dashboard`, `/learn/*`, `/plan`, `/practice`, `/community`, `/career`, `/teacher`.

Поток нового пользователя: лендинг → «Пройти диагностику» → `/career?from=onboarding` (профориентация) → `/onboarding` (диагностика уровня по выбранным предметам) → `/dashboard`.

### Бэкенд и данные

- Таблицы: `profiles`, `diagnostic_results`, `lesson_progress`, `user_novas` и др.; доступ только через RLS-политики (`(select auth.uid()) = id`).
- Профиль создаётся автоматически триггером `handle_new_user()` при регистрации.
- Валюта «Новасы»: начисление — триггерами БД, списание — auth-scoped RPC `spend_novas`.
- Edge-функции: `ai-chat` (прокси к LLM с shared-secret авторизацией) и `dispatch-notification-push` (Web Push по VAPID).

### Интернационализация

Весь UI на трёх языках. Контракт — `utils/i18n.ts` (`loc(lang, text)`, kk делает fallback на ru) и `context/LanguageContext.tsx`. Общего файла переводов нет: каждый компонент владеет своими строками в виде `Localized`-констант в начале файла. Язык по умолчанию — русский, выбор хранится в `localStorage` (`novex.lang`).

### Дизайн-система

Светлая тема, палитра зафиксирована (токены `canvas`, `ink`, `teal`, `teal-dark`, `teal-light`, `mist`, `coral`, `slateink`, `line` — объявлены в `@theme` в `index.css`; сырой hex в `className` запрещён). Шрифты: Manrope (заголовки), Inter (текст), JetBrains Mono (микро-подписи роботов). Все иллюстрации и моки продукта — инлайн-JSX и SVG, без внешних запросов за картинками: страница полностью рендерится офлайн и быстро работает на слабом интернете. Анимации — `framer-motion` fade-up с уважением к `prefers-reduced-motion`; семантические лендмарки и фокус-кольца для доступности.

## Начало работы

```bash
npm install
npm run dev       # dev-сервер на http://localhost:3000
npm run build     # продакшн-сборка в dist/
npm run preview   # предпросмотр сборки
```

Для локальной разработки нужен `.env.local` (шаблон — `.env.example`):

```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
VITE_VAPID_PUBLIC_KEY=...
```

Все `VITE_*`-переменные публичны по задумке — секреты (ключи LLM-провайдеров и т.п.) хранятся только в секретах Supabase Edge Functions. `.env`-файлы не коммитятся.

Тест-раннер в проекте пока не настроен; проверка — `npm run build` (TypeScript strict, ноль ошибок) и ручной прогон в dev.

## Деплой

Проект развёрнут на Vercel (`vercel.json`): сборка `npm run build`, вывод `dist/`, SPA-роутинг через rewrites. Дополнительно на все ответы навешиваются security-заголовки (CSP, HSTS, X-Frame-Options и др.). Продакшн: [novex-edu.vercel.app](https://novex-edu.vercel.app).
